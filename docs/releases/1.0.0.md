This is the first SlackMinecraft release. It connects Minecraft chat and server activity with a Slack channel.

## What changed

- Send chat between Minecraft and one Slack channel.
- Share player joins, quits, deaths and advancements in Slack.
- Show player names and avatars on outgoing messages.
- Convert known user mentions between Minecraft and Slack.
- Customise the bot name and server notification text.

## Installation and updating

1. Stop your Minecraft server.
2. If SlackMinecraft is already installed, back up `plugins/SlackMinecraft/config.yml` and remove the previous plugin JAR.
3. Put the attached `SlackMinecraft-Build-1.0.jar` in `plugins/`.
4. Start the server. For a first installation, stop it again and enter your Slack settings in `plugins/SlackMinecraft/config.yml`.
5. Restart after any configuration changes and check that chat works in both directions.

See this version's [default configuration](https://github.com/Staticpast/SlackMinecraft/blob/v1.0.0/src/main/resources/config.yml) for its settings.

## Requirements

- Original server target: Spigot for Minecraft 1.15.1.
- Original Java target: Java 8.

This is a legacy release. Compatibility with current Minecraft servers and Slack has not been verified.
