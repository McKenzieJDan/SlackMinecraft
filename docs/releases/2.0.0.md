## New

- Support for Spigot/Paper 26.2 and Java 25.
- Slack Socket Mode connection with user mentions and player event notifications.
- Slack commands `!list`, `!status` and `!tps` for server information.
- Administrator commands to exclude players from outgoing relay.
- Channel ID support and paginated channel lookup.

## Fixed

- Plugin startup failure caused by missing command registration.
- Connection setup that blocked online notifications and user-cache refreshes.
- Minecraft broadcasts and player queries running outside the server thread.
- User-cache loss after a failed refresh and incorrect mention escaping.
- Resource cleanup when the plugin stops.

## Changed

- Command echoing defaults to off and sends command names only. Arguments are never sent.
- Cancelled chat and commands are excluded from relay. Recipe unlocks do not produce advancement notifications.
- Outgoing messages use a bounded queue and limited rate-limit retries.
- Updated Slack dependencies and added regression and packaged-JAR checks.

## Installation

Requires Spigot/Paper 26.2 and Java 25. Download the attached `SlackMinecraft-2.0.0.jar`, stop your server and replace the previous plugin JAR in `plugins/`.

Back up your configuration before upgrading. Existing values are retained. Check the updated [setup guide](https://github.com/Staticpast/SlackMinecraft/blob/v2.0.0/docs/setup.md) for Slack permissions and event subscriptions, then restart your server.

Older Minecraft versions and Folia are not supported by this build.

## Validation

The release command runs the automated tests and checks the packaged JAR locally. Live server-to-workspace testing remains unverified.
