## Fixed

- Preserve Slack's rate-limit cooldown for subsequent messages after the current message exhausts its three send attempts.
- Stop retrying Socket Mode startup when the worker is interrupted.
- Check for shutdown before sending a message after a pacing wait.

## Changed

- Separate outgoing request construction, pacing and retries into `SlackDelivery`. The relay worker retains ownership of the queue and connections.
- Add regression tests for rate limits, uncertain delivery, startup cleanup, shutdown during sends, and ignore-command permissions and persistence.
- Update the architecture documentation to describe delivery and shutdown behaviour.

## Installation

Requires Spigot/Paper 26.2 and Java 25. Download the attached `SlackMinecraft-2.0.1.jar`, stop your server and replace the previous plugin JAR in `plugins/`.

Existing configuration values and ignored players are retained. No configuration or Slack permission changes are required when upgrading from 2.0.0. See the [setup guide](https://github.com/Staticpast/SlackMinecraft/blob/v2.0.1/docs/setup.md) for installation details.

## Validation

The release command runs 63 unit and regression tests and two packaged-JAR checks locally before publishing. Live Minecraft-to-Slack testing remains unverified.
