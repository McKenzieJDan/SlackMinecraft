This update improves message delivery when Slack limits how quickly the server can send messages, and makes server shutdown more reliable.

## What changed

- When Slack asks the plugin to wait, that wait now applies to subsequent messages even if the current message could not be delivered. This reduces repeated rejections during busy periods.
- Connection attempts stop promptly when the plugin shuts down.
- Messages waiting for a delivery delay are no longer sent after shutdown begins. The offline notification remains best effort.

## Installation and updating

1. Stop your Minecraft server.
2. If SlackMinecraft is already installed, back up `plugins/SlackMinecraft/config.yml` and remove the previous plugin JAR.
3. Put the attached `SlackMinecraft-2.0.1.jar` in `plugins/`.
4. For a first installation or an upgrade from 1.x, follow the [setup guide](https://github.com/Staticpast/SlackMinecraft/blob/v2.0.1/docs/setup.md) to configure your Slack app and tokens.
5. Start the server and check that chat works in both directions.

When upgrading from 2.0.0, your settings and ignored-player list are retained. No configuration changes or Slack app permission changes are needed.

## Requirements

- Spigot or Paper for Minecraft 26.2.
- Java 25.

Older Minecraft versions and Folia are not supported.
