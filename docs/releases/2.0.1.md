This update improves message delivery when Slack limits how quickly the server can send messages, and makes server shutdown more reliable.

## What changed

- When Slack asks the plugin to wait, that wait now applies to subsequent messages even if the current message could not be delivered. This reduces repeated rejections during busy periods.
- Connection attempts stop promptly when the plugin shuts down.
- Messages waiting to be sent are discarded when the plugin shuts down. The offline notification remains best effort.

## Updating from 2.0.0

1. Stop your Minecraft server.
2. Back up `plugins/SlackMinecraft/config.yml`.
3. Replace the existing SlackMinecraft plugin JAR in `plugins/` with the attached `SlackMinecraft-2.0.1.jar`.
4. Start the server and check that chat works in both directions.

Your settings and ignored-player list are retained. No configuration changes or Slack app permission changes are needed.

## Requirements

- Spigot or Paper for Minecraft 26.2.
- Java 25.

Older Minecraft versions and Folia are not supported. For a first installation, follow the [setup guide](https://github.com/Staticpast/SlackMinecraft/blob/v2.0.1/docs/setup.md).

## Testing status

Automated build and plugin checks pass. This release has not yet been tested on a live Minecraft server connected to Slack.
