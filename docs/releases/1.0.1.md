This update adds a custom icon for server notifications and updates their default wording.

## What changed

- Set `slack.icon` to choose the image shown on server notifications in Slack.
- Change the default bot name from “Server” to “Minecraft”.
- Use “Online” and “Offline” for the default connection notifications.
- Show the default join and quit messages in italics.

## Installation and updating

1. Stop your Minecraft server.
2. If SlackMinecraft is already installed, back up `plugins/SlackMinecraft/config.yml` and remove the previous plugin JAR.
3. Put the attached `SlackMinecraft-Build-1.0.1.jar` in `plugins/`.
4. Start the server. For a first installation, stop it again and enter your Slack settings in `plugins/SlackMinecraft/config.yml`.
5. Restart after any configuration changes and check that chat works in both directions.

See this version's [default configuration](https://github.com/Staticpast/SlackMinecraft/blob/v1.0.1/src/main/resources/config.yml) for its settings.

## Requirements

- Original server target: Spigot for Minecraft 1.15.1.
- Original Java target: Java 8.

This is a legacy release. Compatibility with current Minecraft servers and Slack has not been verified.
